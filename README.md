# Movilidad Urbana

Este proyecto consiste en el desarrollo de una simulación multiagente de tráfico urbano que busca representar y analizar el comportamiento de los vehículos dentro de una ciudad, con el objetivo de explorar soluciones que ayuden a reducir la congestión vial. A través de agentes autónomos, cada vehículo se desplaza por las calles siguiendo su dirección correspondiente, respetando los semáforos, evitando obstáculos y colisiones, y buscando llegar a un destino determinado. La simulación utiliza un entorno urbano en 3D, conectado mediante Mesa y WebGL, que permite visualizar el comportamiento de los agentes y la interacción entre ellos en tiempo real. De esta manera, el proyecto busca representar de forma gráfica cómo funciona el tráfico y cómo la coordinación entre vehículos puede contribuir a una movilidad urbana más eficiente.
